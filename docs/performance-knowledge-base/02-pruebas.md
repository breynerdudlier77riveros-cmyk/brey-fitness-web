# 02 · Fichas de prueba

Once pruebas documentadas. Cada ficha responde las mismas trece preguntas; una sección sin
respaldo se marca **«Evidencia insuficiente»**, que es información útil y no un hueco.

Las fichas **no contienen protocolos**. Cómo ejecutar una prueba pertenece a su documento de
referencia; aquí se documenta qué se sabe de ella.

---

## P-01 · 1RM (una repetición máxima)

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-A · Fuerza |
| **Qué mide** | La carga máxima movilizable una vez en un ejercicio concreto |
| **Qué NO mide** | Fuerza máxima general; fuerza de otros patrones; potencia; rendimiento deportivo |
| **Población estudiada** | Adultos jóvenes y de mediana edad, adultos mayores; con y sin experiencia previa; ambos sexos [`grgic_1rm_2020`] |
| **Población NO estudiada** | Niños y adolescentes; poblaciones clínicas |
| **Fiabilidad** | **Alta.** ICC 0,64-0,99 (mediana 0,97); 92% ≥ 0,90. CV mediana 4,2% |
| **Validez** | De criterio para la carga máxima del ejercicio evaluado: es la medida directa. De constructo para «fuerza máxima» como dimensión: **insuficiente** |
| **Sensibilidad al cambio** | Evidencia insuficiente en v1.0 |
| **Factores que alteran** | Familiarización, técnica, fatiga previa, motivación, equipamiento, criterio del evaluador para validar el intento |
| **Confusión** | Aprendizaje técnico del ejercicio: los primeros aumentos pueden ser habilidad, no fuerza |
| **Errores frecuentes** | Comparar 1RM entre ejercicios distintos; estimar 1RM desde repeticiones submáximas y tratarlo como medido |
| **Prohibido** | «Más fuerza implica mejor rendimiento». «Un 1RM alto en sentadilla predice el de press» |
| **Referencias** | `grgic_1rm_2020`, `acsm_guidelines_11` |

## P-03 · Dinamometría de agarre

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-C · Agarre |
| **Qué mide** | Fuerza isométrica máxima de prensión manual |
| **Qué NO mide** | **Fuerza global.** No representa la fuerza de tren superior, tren inferior ni tronco |
| **Población estudiada** | Adultos mayores [`bohannon_grip_2019`]; población general adulta, 2,4 millones de personas en 69 países [`hgs_normas_internacionales`]; cohortes observacionales amplias [`soysal_hgs_2021`] |
| **Población NO estudiada** | Atletas de alto nivel como grupo diferenciado |
| **Fiabilidad** | Alta según las fuentes consultadas; no se verificó una revisión sistemática dedicada exclusivamente a fiabilidad |
| **Validez** | Como marcador de estado general en adultos mayores: respaldada. Como índice de fuerza de otras regiones: **no respaldada** |
| **Sensibilidad al cambio** | Evidencia insuficiente en v1.0 |
| **Factores que alteran** | Posición del codo, tipo de dinamómetro, calibración, instrucción, mano dominante, hora del día |
| **Confusión** | Edad y sexo dominan la varianza: comparar sin estratificar es comparar edades |
| **Errores frecuentes** | Usarla como sustituto barato de la fuerza general |
| **Prohibido** | «Agarre bajo significa riesgo de muerte en este atleta». Las asociaciones son observacionales, poblacionales y **ninguna alcanzó evidencia convincente** |
| **Referencias** | `soysal_hgs_2021`, `bohannon_grip_2019`, `hgs_normas_internacionales` |

## P-04 · CMJ (salto con contramovimiento)

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-B · Salto |
| **Qué mide** | Altura alcanzada en un salto vertical con contramovimiento |
| **Qué NO mide** | Potencia, salvo que se midan fuerza y tiempo. **La altura es un desplazamiento** |
| **Población estudiada** | Atletas y adultos activos |
| **Población NO estudiada** | Adultos mayores; poblaciones clínicas |
| **Fiabilidad** | Alta y ampliamente replicada, con variación según instrumento y variable |
| **Validez** | De criterio para la altura: alta con instrumentación adecuada. De constructo para «potencia»: **insuficiente** |
| **Sensibilidad al cambio** | Evidencia insuficiente en v1.0 |
| **Factores que alteran** | Uso de brazos, profundidad del contramovimiento, calzado, superficie, método de cálculo (tiempo de vuelo frente a impulso-momento) |
| **Confusión** | El método de cálculo cambia el número: dos sistemas no son intercambiables sin comprobarlo |
| **Errores frecuentes** | Comparar alturas obtenidas con métodos distintos; llamar «potencia» a la altura |
| **Prohibido** | «Mayor salto significa menor riesgo de lesión». «El CMJ mide la potencia del atleta» |
| **Referencias** | Fiabilidad ampliamente documentada; **no se registró una revisión sistemática única** que la consolide, y por eso esta ficha no cita clave. Ver `12-roadmap.md`, deuda D-02 |

## P-05 · Drop jump / RSI (índice de fuerza reactiva)

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-B · Salto |
| **Qué mide** | Relación entre altura de salto y tiempo de contacto con el suelo |
| **Qué NO mide** | Fuerza máxima; potencia; rendimiento deportivo directamente |
| **Población estudiada** | Individuos sanos a lo largo del ciclo vital [`rsi_metaanalisis_2021`] |
| **Fiabilidad** | Buena cuando hay familiarización previa (CV ≤ 10%, ICC ≥ 0,8 en la evidencia consultada) |
| **Validez** | Asociaciones con medidas de rendimiento físico y deportivo [`rsi_metaanalisis_2021`] |
| **Sensibilidad al cambio** | Responde al entrenamiento pliométrico según la fuente |
| **Factores que alteran** | Altura de caída, instrucción («salta lo más alto» frente a «minimiza el contacto»), familiarización |
| **Confusión** | **El índice oculta sus componentes.** Un RSI estable puede esconder una altura que sube y un tiempo de contacto que también sube |
| **Errores frecuentes** | Informar el RSI sin altura ni tiempo de contacto. La propia fuente lo desaconseja explícitamente |
| **Prohibido** | Interpretar un cambio de RSI sin saber cuál de sus dos componentes cambió |
| **Referencias** | `rsi_metaanalisis_2021` |

## P-06 · Sit-and-reach

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-E · Movilidad y flexibilidad |
| **Qué mide** | Extensibilidad isquiosural, de forma aproximada (r ≈ 0,46-0,67) |
| **Qué NO mide** | **Flexibilidad lumbar** (validez baja). Tampoco movilidad activa, ni «flexibilidad general» |
| **Población estudiada** | Adultos jóvenes recreacionales; adultos mayores [`mayorga_sit_reach_2014`] |
| **Población NO estudiada** | Atletas de alto nivel como grupo diferenciado |
| **Fiabilidad** | Alta: es una medida de distancia con protocolo simple |
| **Validez** | **Moderada** para extensibilidad isquiosural. **Baja** para extensibilidad lumbar |
| **Sensibilidad al cambio** | Evidencia insuficiente en v1.0 |
| **Factores que alteran** | Longitud relativa de segmentos, temperatura, calentamiento previo, hora del día, versión de la prueba |
| **Confusión** | **Proporciones corporales.** Brazos largos y piernas cortas alcanzan más sin más extensibilidad |
| **Errores frecuentes** | Leerla como medida de salud lumbar; comparar entre versiones distintas de la prueba |
| **Prohibido** | «Menos alcance significa más riesgo de lumbalgia». «Mide la flexibilidad del atleta» |
| **Referencias** | `mayorga_sit_reach_2014` |

## P-08 · Y-Balance Test (cuadrante inferior)

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-F · Equilibrio |
| **Qué mide** | Alcance en tres direcciones sobre una pierna: control postural dinámico |
| **Qué NO mide** | **Riesgo de lesión.** Tampoco estabilidad articular ni calidad de movimiento |
| **Población estudiada** | Adultos sanos; deportistas de varias modalidades [`plisky_ybt_2021`, `sebt_ybt_fiabilidad_2019`] |
| **Fiabilidad** | Intraevaluador **alta** (0,85-0,91). De moderada a alta en adultos sanos |
| **Validez** | Discriminante documentada. **Predictiva de lesión: limitada** — 3/13, 3/10 y 1/13 estudios según el índice |
| **Sensibilidad al cambio** | Responde a programas de entrenamiento según la literatura sobre SEBT |
| **Factores que alteran** | Longitud de pierna (obliga a normalizar), calzado, número de intentos, aprendizaje |
| **Confusión** | Aprendizaje de la tarea: mejora sin cambio en el control postural |
| **Errores frecuentes** | Aplicar puntos de corte generales. **La propia fuente lo desaconseja** |
| **Prohibido** | «Asimetría > 4 cm significa riesgo de lesión». Los requisitos son específicos de población |
| **Referencias** | `plisky_ybt_2021`, `sebt_ybt_fiabilidad_2019` |

## P-09 · FMS (Functional Movement Screen)

| Campo | Contenido |
|---|---|
| **Familia PAS** | F-G · Estabilidad y control |
| **Qué mide** | Una puntuación compuesta de siete movimientos evaluados por un observador |
| **Qué NO mide** | **Riesgo de lesión.** Tampoco competencia técnica de un patrón concreto ni control motor como capacidad |
| **Población estudiada** | Deportistas de varias modalidades, adultos activos, personal militar y policial |
| **Fiabilidad** | No se verificó aquí una revisión dedicada a fiabilidad interevaluador |
| **Validez** | **Predictiva de lesión: no respaldada.** Tres revisiones sistemáticas independientes coinciden |
| **Sensibilidad al cambio** | Las puntuaciones cambian con la intervención, lo que no las convierte en válidas |
| **Factores que alteran** | Experiencia del evaluador; conocimiento previo del atleta; instrucción |
| **Confusión** | Heterogeneidad de resultados por edad, sexo, deporte, definición de lesión y mecanismo [`moore_fms_2019`] |
| **Errores frecuentes** | Usar el punto de corte de 14 como umbral de riesgo |
| **Prohibido** | **«FMS ≤ 14 predice lesión».** La conclusión literal de los autores es que la asociación NO respalda su uso como herramienta de predicción [`moran_fms_2017`] |
| **Referencias** | `moran_fms_2017`, `moore_fms_2019`, `bunn_fms_2019` |
