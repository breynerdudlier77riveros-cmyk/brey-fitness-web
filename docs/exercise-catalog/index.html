BREY Exercise Catalog v1.0

El contrato del catálogo oficial de ejercicios

BREY Exercise Catalog

Taxonomy definió qué atributos existen. Tagging definió cómo se asignan. Este handbook define qué es un ejercicio oficial del ecosistema: el modelo completo de 21 atributos, las condiciones de existencia, la integridad, el versionado y quién puede modificarlo. Cero fichas, cero ejercicios, cero biomecánica — solo el contrato que cualquier entrada del catálogo debe cumplir.
