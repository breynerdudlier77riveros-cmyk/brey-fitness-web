Preguntas Abiertas

Doce preguntas sin resolver — heredadas de handbooks anteriores o propias de este contrato. Ninguna se cierra aquí: hacerlo sería inventar una decisión de producto o de dominio que ningún handbook ha tomado todavía.

Por qué esta lista no se resuelve

Cerrar cualquiera de estas preguntas en este documento violaría la restricción explícita del encargo original: sin funcionalidad nueva, sin inventar. Cada una depende de un handbook futuro (Recovery Engine completo, Coach IA) o de una decisión de producto que corresponde a otro documento o a otro momento.
