Módulo 13 · Comportamiento

Estados

Todo lo que no es "el camino feliz" — cada uno con su propio tratamiento visual, nunca un error genérico de sistema.

Consolidación

El encargo lista "Offline" y "Sin internet" como dos estados separados — se tratan aquí como el mismo estado (conectividad de red ausente), documentado una sola vez para evitar dos especificaciones divergentes de lo mismo.

Los 7 estados

EstadoDisparadorTratamiento visual
VacíoCliente sin ninguna Medición registrada (BCS Handbook, 04)Ilustración simple + texto "Sin mediciones registradas" + botón "Registrar la primera medición"
ErrorError de invocación (validación fallida, error de red al guardar)Warning Card (BCS-C04, 06) con mensaje específico, nunca un código de error crudo — el formulario conserva los datos ya ingresados
CargaCualquier operación asíncrona en curso >150ms (16)Skeleton (BCS-C07, 06) con la forma exacta del contenido que va a aparecer
Offline / sin internetSin conexión de red detectadaBanner persistente en la parte superior — el panel del entrenador sigue mostrando el último estado conocido, marcado como "posiblemente desactualizado"
Sin historialSe solicita Comparación (12) o gráfico de tendencia con <2 Mediciones vigentesEsa sección específica se omite con nota — nunca toda la pantalla, solo la sección que depende de historial (BCS Handbook, 04)
Sin datos suficientesUna variable concreta ausente en la Medición actual (BCS Handbook, 03)La Metric Card (BCS-C01) correspondiente no se renderiza — nunca aparece con un placeholder tipo "—" que podría confundirse con un valor real de cero
Sin permisoToken de EnlacePúblico inválido o revocado (BCS Handbook, 10)Pantalla dedicada de página completa: "Este enlace ya no está disponible" — sin revelar si el token existió alguna vez (BCS Handbook, 08)

Contraejemplos

  • Ningún estado de error muestra un stack trace ni un código HTTP crudo al entrenador.
  • El estado Vacío nunca se confunde visualmente con el estado Error — usan componentes e iconografía distintos.
