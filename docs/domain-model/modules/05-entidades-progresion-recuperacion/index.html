Módulo 05 · Entidades

Entidades de Progresión y Recuperación

Seis entidades — tres de Progression (persistentes/derivadas) y tres de Recovery (mayormente efímeras, salvo su resultado).

PR-01especificado

Prescripción

Descripción
El conjunto de valores asignado a un Slot para el próximo ciclo (LU-16).
Identidad
1:1 con el Slot que la recibe — se reemplaza atómicamente, nunca se edita parcialmente (Progression Engine Handbook, IN-M2)
Naturaleza
Persistente — es la entrada real que el Workout Generator consume
Relaciones
Producida por una Decisión micro de Progression Engine; consumida por el Slot correspondiente en el siguiente Workout
PR-02especificado

EvaluaciónProgresión

Descripción
El resultado del pipeline de 9 pasos de Progression Engine para un ciclo dado — Decisión micro y/o macro, con razón y contexto.
Identidad
Efímera en sí misma — su forma persistida es el EventoProgresión (PR-03)
Naturaleza
Derivada — se recalcula determinísticamente a partir de la Ventana de historial, nunca se persiste como entidad separada del evento que produce
Relaciones
Consume Ventana de historial + Prescripción vigente + EstadoRecuperación (Veredicto); produce una Prescripción nueva y/o un evento
PR-03especificado

EventoProgresión

Descripción
El registro persistido de una EvaluaciónProgresión — la forma real que sobrevive en progression_events (Engineering Handbook, 07).
Identidad
Propia — id uuid, append-only
Naturaleza
Persistente — nunca editado ni borrado tras su creación (FT-09)
Relaciones
Referencia un Usuario, opcionalmente un WorkoutLog origen; su tipo lo clasifica entre 25 valores consolidados (Domain Events, 11)
PR-04especificado

EstadoRecuperación

Descripción
El Veredicto ya resuelto que Recovery Engine entrega a Motor BPS/Progression Engine — forma canónica reconciliada por el Implementation Handbook (IMP-ADR-01): {procede: boolean, subtipo?: "programada"|"reactiva", razon: string}.
Identidad
Efímero — no tiene identidad propia persistida; su efecto se registra indirectamente vía EventoProgresión cuando dispara una Descarga
Naturaleza
Derivado — se recalcula en cada ciclo a partir de SeñalFatiga
Relaciones
Consumido por Motor BPS y Progression Engine como entrada obligatoria, nunca calculado por ninguno de los dos
PR-05especificado

SeñalFatiga

Descripción
Dato crudo de fatiga/dolor/sueño — propiedad exclusiva de Recovery Engine.
Identidad
Fuera de alcance de este handbook — Recovery Engine no tiene handbook de dominio propio (00, Architecture Review AR-006)
Naturaleza
Efímera para el resto del ecosistema — ningún otro contexto la persiste ni la observa directamente (P8, LU-18)
Relaciones
Consumida exclusivamente por Recovery Engine para producir EstadoRecuperación
PR-06especificado

Descarga

Descripción
Reducción de volumen/intensidad aplicada a una Prescripción — tres tipos: programada (Training Framework), reactiva (Recovery, terminal), preventiva (Progression Engine, no vinculante, PE-035, 🔴 hipótesis).
Identidad
Efímera como decisión, persistente como efecto (la Prescripción resultante y el EventoProgresión que la originó)
Naturaleza
Derivada — nunca es una entidad con tabla propia, es una clasificación de por qué una Prescripción cambió
Relaciones
Prioridad entre tipos cuando coinciden: reactiva > programada > preventiva (Progression Engine Handbook, PE-037)
