Módulo 01 · Fundamentos

Lenguaje Ubicuo

21 términos oficiales. Cada uno con su definición, sus sinónimos permitidos, sus términos prohibidos y el handbook donde se originó — nunca un término nuevo introducido sin decir de dónde viene.

LU-01

Usuario

Definición
Identidad autenticada real del Core Product — una fila de auth.users + su profile asociado. El término genérico de identidad en todo el ecosistema.
Sinónimos permitidos
"Cuenta" (en contexto de autenticación exclusivamente)
Términos prohibidos
"Miembro", "Suscriptor" — no usados en ningún handbook existente
Handbook de origen
Architecture Handbook
LU-02

Entrenador

Definición
Un Usuario (LU-01) en su rol de administrador de una cartera de Clientes dentro del Body Composition System. No es una identidad distinta — es el mismo Usuario, nombrado por su función en ese contexto específico.
Sinónimos permitidos
Ninguno — "Entrenador" es el único término en el contexto del BCS
Términos prohibidos
"Coach" (reservado para el futuro módulo Coach IA, un concepto distinto), "Admin"
Handbook de origen
Body Composition System Handbook
LU-03

Cliente

Definición
Persona presencial que el Entrenador mide en el contexto del BCS. Explícitamente no es un Usuario — no tiene login, no tiene sesión, no existe en auth.users. Es una entidad propia del bounded context Body Composition.
Sinónimos permitidos
Ninguno dentro del BCS
Términos prohibidos
"Usuario del BCS", "Cuenta de cliente" — ninguno de los dos existe; confundir Cliente con Usuario es el error de lenguaje más peligroso de todo el ecosistema (02)
Handbook de origen
Body Composition System Handbook (00, 01)
LU-04

Diagnóstico

Definición
El proceso y resultado de responder el cuestionario BPS que determina el Nivel de entrada de un Usuario en un Sistema.
Sinónimos permitidos
"Diagnóstico BPS" (forma completa, usada en contexto ambiguo)
Términos prohibidos
"Quiz" — término retirado explícitamente (redirect /quiz → /diagnostico ya real en el código)
Handbook de origen
Architecture Handbook
LU-05

Sistema

Definición
Un producto comercial de BREY — la plantilla de entrenamiento (Calistenia, Hipertrofia, Híbrido, Fuerza, Elite). Es catálogo, no instancia (P5 del Architecture Handbook, "Plantilla ≠ Instancia").
Sinónimos permitidos
Ninguno
Términos prohibidos
"Programa" como sinónimo de Sistema — ver LU-06, esta confusión es real y documentada
Handbook de origen
Architecture Handbook
LU-06

Programa

Definición
La instancia personalizada de un Sistema para un Usuario específico — el resultado de aplicar Sistema + Nivel + Diagnóstico a ese Usuario. Un Programa es al Sistema lo que un objeto es a su clase (P5).
Sinónimos permitidos
Ninguno
Términos prohibidos
Ninguno adicional, pero ver la nota de desambiguación abajo
Handbook de origen
Este handbook (síntesis explícita, ver nota)
Nota de desambiguación — "Programa" no es un término deprecado

El código real de BREY (next.config.ts) redirige /programas → /sistemas — pero ese redirect es de navegación de marketing (la URL pública donde se compra un Sistema), no una decisión sobre el vocabulario de dominio. "Programa" como la instancia personalizada de un Sistema es un concepto que ningún handbook anterior nombró explícitamente, pero que P5 (Plantilla ≠ Instancia) ya exige que exista conceptualmente. Este documento lo formaliza aquí, sin contradecir el redirect (que sigue rigiendo exclusivamente la URL de catálogo comercial).

LU-07

Track

Definición
Variante de ejecución de un Sistema (ej. Gym/Casa) — un eje independiente del Nivel.
Sinónimos permitidos
Ninguno
Términos prohibidos
"Modalidad", "Variante" — no usados en ningún handbook
Handbook de origen
Architecture Handbook
LU-08

Nivel

Definición
profiles.nivel_actual — asignado por Diagnóstico/Motor BPS, acoplado a un Sistema específico (ej. "Skills" solo existe en Calistenia). Nunca confundir con nivel_experiencia (autorreportado, sin uso algorítmico, ADR-003 del Architecture Handbook).
Sinónimos permitidos
Ninguno
Términos prohibidos
"Rango", "Grado"
Handbook de origen
Architecture Handbook (ADR-003)
LU-09

Bloque

Definición
Escalón de la jerarquía de entrenamiento compuesto de Mesociclos — posición dentro de un Nivel.
Handbook de origen
Architecture Handbook (Training Framework) — profundizado en Motor BPS Handbook y Progression Engine Handbook
LU-10

Mesociclo

Definición
Escalón compuesto de Microciclos, dentro de un Bloque.
Handbook de origen
Architecture Handbook — profundizado en Progression Engine Handbook (09, escalera de macroprogresión)
LU-11

Microciclo

Definición
El escalón más frecuente de la jerarquía — una semana de entrenamiento, compuesta de Workouts.
Handbook de origen
Architecture Handbook — profundizado en Motor BPS Handbook ("ciclo semanal")
LU-12

Workout

Definición
Una sesión de entrenamiento planificada — implementado, tabla real workouts.
Sinónimos permitidos
"Entrenamiento", "Sesión" (en prosa, nunca como nombre de entidad)
Términos prohibidos
Ninguno
Handbook de origen
Architecture Handbook
LU-13

Slot

Definición
Posición dentro de un Workout, identificada por Patrón×Rol — nunca por el nombre de un Ejercicio concreto (P7 del Architecture Handbook).
Handbook de origen
Progression Engine Handbook (03)
LU-14

Ejercicio

Definición
El movimiento concreto que resuelve un Slot — propiedad de la Knowledge Base, nunca conocido por nombre por los motores de progresión (P7).
Handbook de origen
Architecture Handbook (Knowledge Base)
LU-15

Serie

Definición
La unidad mínima de ejecución dentro de un Slot — una repetición agrupada de un Ejercicio con su carga/tempo/descanso.
Handbook de origen
Progression Engine Handbook (08, microprogresión)
LU-16

Prescripción

Definición
El conjunto de valores (peso, repeticiones, series, tempo, descanso, RPE/RIR objetivo, duración, volumen, densidad) asignado a un Slot para el próximo ciclo.
Sinónimos permitidos
"Prescripción vigente" (forma completa, forma oficial de Progression Engine Handbook)
Handbook de origen
Progression Engine Handbook (03, 04)
LU-17

Recuperación

Definición
El dominio conceptual gobernado por Recovery Engine — interpreta fatiga/dolor/sueño y produce un Veredicto. especificado como contrato mínimo (Implementation Handbook, IMP-ADR-01/02); sin handbook de dominio propio todavía.
Sinónimos permitidos
"Recovery Engine" (nombre del motor que gobierna este dominio)
Handbook de origen
Citado por Motor BPS Handbook y Progression Engine Handbook, formalizado por Implementation Handbook
LU-18

Fatiga

Definición
Señal cruda interpretada exclusivamente por Recovery Engine — ningún otro motor (Motor BPS, Progression Engine) la recibe directamente, solo el Veredicto ya resuelto (P8).
Términos prohibidos
Usar "Fatiga" como si fuera un campo del contrato de entrada de Progression Engine — no lo es (10 del Progression Engine Handbook)
Handbook de origen
Progression Engine Handbook (10) — como frontera, no como dato consumido
LU-19

Medición

Definición
Captura puntual de composición corporal de un Cliente, con fecha y hasta 25 variables — aggregate root propio del BCS.
Handbook de origen
Body Composition System Handbook (02, 03)
LU-20

Reporte

Definición
Vista computada a partir de un Cliente y sus Mediciones vigentes — nunca persistida independientemente, siempre refleja el estado actual (IN-D3 del BCS Handbook).
Handbook de origen
Body Composition System Handbook (04)
LU-21

Enlace Público

Definición
Token de acceso de solo lectura al Reporte de un Cliente — aggregate root propio, nunca contenido dentro del aggregate Cliente (BCS-ADR-01).
Sinónimos permitidos
"EnlacePúblico" (una sola palabra, forma técnica usada en el BCS Handbook)
Términos prohibidos
"Permiso", "Credencial" — el Enlace Público nunca es un mecanismo de autorización, ver 14 (Anti-Patrones)
Handbook de origen
Body Composition System Handbook (09, 10)
