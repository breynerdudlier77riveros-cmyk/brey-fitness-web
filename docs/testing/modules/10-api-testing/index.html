API Testing

Los 45 endpoints del catálogo (API Contract Handbook, 07), uno por uno, con el foco exacto de su prueba de integración — contrato de entrada/salida, autorización, e idempotencia donde aplique.

45 endpoints trazados Nivel integration por defecto

Qué verifica un test de integración de endpoint, siempre

  • El request con forma válida produce el status y el envelope exactos especificados (API Contract Handbook, 06, 09).
  • El request con forma inválida produce el error de dominio o infraestructura exacto, nunca un 500 genérico.
  • El actor sin autorización recibe 401/403/404 según corresponda (API Contract Handbook, 09, 13) — nunca una fuga de existencia del recurso.
