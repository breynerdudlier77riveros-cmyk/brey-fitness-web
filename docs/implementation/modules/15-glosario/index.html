Módulo 15 · Checklists y gobernanza

Glosario

Todo término propio de este handbook, en orden alfabético.

TérminoDefinición
bloqueado (estado)Tiene una precondición real sin cumplir — no puede empezar hoy (00, 12)
contrato mínimoLa forma de datos estrictamente necesaria para desbloquear a los consumidores de un motor sin handbook completo — el caso de Recovery Engine (08, IMP-ADR-02)
Definition of DoneCriterio para marcar una pieza como implementado o verificado (01)
Definition of ReadyCriterio para empezar a construir una pieza — handbook auditado, contratos resueltos, sin brecha de seguridad abierta (01)
en progreso (estado)Parcialmente construido — ejemplo real: el motor de Diagnóstico BPS, implementado pero sin persistencia (12)
FaseUna de las 5 etapas del Roadmap (03) — 0 Fundación, 1 Pista A/B, 2 Integración, 3 Endurecimiento, 4 Expansión futura
implementado (estado)Construido y funcional, pendiente del checklist de Release para ser verificado (00)
IMP-ADRDecisión de arquitectura propia de este handbook — de secuenciación u orquestación, nunca de dominio (14)
no iniciado (estado)Sin precondición pendiente, pero sin trabajo empezado todavía (12)
orquestarFijar orden y condiciones de entrada/salida entre piezas ya especificadas — lo único que hace este handbook (00)
Pista A / Pista BLos dos flujos de trabajo paralelos de la Fase 1 — BCS (A) y Motores (B), autorizados a correr en paralelo por IMP-ADR-03 (02, 03)
verificado (estado)Implementado y confirmado con el checklist de Release completo — el estado más alto de la escala (00, 13)
