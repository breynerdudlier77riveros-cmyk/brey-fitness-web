Módulo 11 · Datos y visualización

Sistema de gráficos

Seis tipos de gráfico evaluados — solo tres entran en v1. Los otros tres se descartan con razón explícita, no por omisión.

Qué usar en v1

TipoCuándo usarlo
LíneaTendencia de una sola variable en el tiempo — el tipo dominante del sistema (09, mayoría de métricas)
Área apiladaExclusivamente para Agua corporal (09, VIZ-04), donde intracelular + extracelular componen visualmente el total
Barras horizontales de rangoEl Sistema de barras (10) — posición dentro de un rango de referencia citado

Qué NO usar en v1

Decisión formal de excluir Radar y Scatter en BCSD-ADR-04 (20).

TipoPor qué se descarta
RadarComprimir múltiples variables de escalas distintas (kg, %, índices adimensionales) en un mismo radar normalizado implica una decisión de ponderación entre ellas que este sistema no tiene base para tomar — crearía una impresión visual de "balance general" sin fundamento (BCS Handbook, 06). Candidato de v2 si se define una base rigurosa (19).
Columnas verticalesRedundante con Línea para series temporales de una variable — Línea comunica tendencia con más claridad en el espacio angosto de una Metric Card. Columnas sí se usan puntualmente en Comparación (12) para contrastar exactamente 2 fechas lado a lado, no como tipo general.
Scatter (dispersión)Sugiere visualmente una correlación entre dos variables (ej. grasa visceral vs. IMC) que el BCS no tiene autoridad para afirmar — sería fabricar una relación estadística no validada, violando la misma regla que prohíbe inventar rangos clínicos (BCS Handbook, 00, 06).

Reglas comunes a todos los gráficos

  • Ningún gráfico interpola entre dos puntos separados por un hueco de tiempo grande como si el dato fuera continuo (BCS Handbook, 07) — el segmento se dibuja con un patrón visual distinto (línea punteada) en vez de sólido.
  • Todo punto marcado como "valor sospechoso" (BCS Handbook, 03) se renderiza con un marcador distinto (borde de advertencia) sin ocultarse ni corregirse automáticamente.
  • Los ejes siempre muestran unidad — nunca un número sin contexto (04, 01 Claridad).
  • Ningún gráfico combina dos variables de unidades distintas en el mismo eje Y.
