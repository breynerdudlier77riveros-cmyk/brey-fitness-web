Módulo 12 · Consistencia

Matrices de Consistencia

Qué combinaciones de atributos son coherentes entre sí. La conclusión más importante de este módulo es negativa: los ejes son ortogonales por diseño, y casi ninguna combinación está prohibida.

Ortogonalidad de los ejes

Un eje, una pregunta

El Rol es "eje independiente del patrón". El equipamiento no condiciona el rol. La modalidad no condiciona el patrón. El barrido no encuentra ninguna regla que prohíba una combinación concreta de valores entre dos ejes distintos.

Consecuencia para el etiquetado: las matrices de este módulo son casi completas, y eso es correcto. Una matriz llena no significa que falte información — significa que los ejes fueron diseñados para no interferir entre sí.

Posible ≠ cubierto

La matriz describe lo estructuralmente posible. Que un slot core × principal sea resoluble depende de que algún ejercicio de patrón core declare principal entre sus roles — es una cuestión de cobertura de catálogo, no de consistencia. Con 0 de 19 ejercicios etiquetados, la cobertura real de las 35 combinaciones es cero.

Simetría exacta entre ejecución y recorte

El orden de recorte es el inverso del orden de ejecución, y los dos primeros roles nunca se recortan. Es la matriz más completamente especificada del handbook — la única laguna es la cifra de descanso de activacion y la función que elige un valor dentro de cada rango.
