Dependencias

El árbol completo de dependencias del ecosistema — corregido. La matriz equivalente del Engineering Handbook (02) contiene un ciclo falso entre Motor BPS y Progression Engine (Architecture Review, AR-005); este módulo es la versión canónica para efectos de secuenciación de construcción.

Corrección aplicada, sin editar el Engineering Handbook

La Architecture Review (AR-005) encontró que el Engineering Handbook (02) declara simultáneamente "Motor BPS depende de Progression Engine" y "Progression Engine depende de Motor BPS" — un ciclo. Verificado contra los dos handbooks de dominio originales (que son consistentes entre sí): la relación real es unidireccional — Motor BPS invoca a Progression Engine como función pura; Progression Engine nunca depende de Motor BPS, solo es llamado por él. Este handbook usa la relación corregida para todo efecto de secuenciación — no se edita el Engineering Handbook, que sigue siendo el documento de arquitectura técnica; este es el documento de orden de construcción.

Dos tipos de relación — nunca se confunden

RelaciónSignificaEfecto en la secuencia de construcción
A depende de BA necesita el contrato/output de B para funcionar — B debe existir (al menos como contrato) antes que AB se construye antes que A, sin excepción
A es invocado por BB llama a A en tiempo de ejecución, pero A no necesita conocer a B para existir — A es una función pura consumible por cualquiera que cumpla su contrato de entradaA y B pueden construirse en paralelo, siempre que el contrato de entrada de A esté fijo primero (Regla 1, 01)
