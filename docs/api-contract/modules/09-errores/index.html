Módulo 09 · Operación

Errores

Todo código de error de dominio, infraestructura, autenticación, autorización y validación del ecosistema, con su status HTTP. Ningún error es "algo salió mal" — cada uno nombra qué falló (P6, Architecture Handbook).

26 códigos de error SNAKE_CASE = dominio · snake_case = infraestructura

Convención de nombres

Un código de error en SNAKE_CASE (mayúsculas) es un error de dominio — ya nombrado por un handbook de negocio (Motor BPS Handbook, BCS Handbook). Un código en snake_case (minúsculas) es un error de infraestructura — el patrón real ya usado por los dos Route Handlers existentes (Engineering Handbook, 06). Este documento no unifica las dos convenciones porque ninguna contradice a la otra — cada una ya identifica de un vistazo a qué categoría pertenece el fallo.

Nota — VENTANA_INSUFICIENTE y SEMANA_YA_GENERADA no están en esta matriz

Ambos son casos de negocio válidos, no errores de cara al actor: VENTANA_INSUFICIENTE resuelve internamente a la decisión sostiene (Progression Engine Handbook, 04) y se registra en el contexto del evento, nunca se devuelve como ok: false; SEMANA_YA_GENERADA devuelve ok: true con la semana ya existente (idempotencia, 11). Incluirlos aquí como "error" contradiría su propia especificación de origen.
