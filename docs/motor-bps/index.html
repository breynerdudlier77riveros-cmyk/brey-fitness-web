Motor BPS Handbook

La especificación completa del orquestador: qué hace, qué no hace, cuándo actúa, cómo decide, cómo resuelve conflictos y cómo conversa con el resto del sistema. Suficiente para implementarlo sin preguntar nada. Si el código lo contradice, el handbook es la verdad.
