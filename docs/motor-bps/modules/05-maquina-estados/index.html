Regla de reparación

La reparación NUNCA borra eventos (P3): reconstruye el puntero desde el replay, registra anomalia con el diagnóstico completo, y solo entonces aplica la degradación de estado más conservadora que los eventos justifiquen. Un estado imposible es siempre un bug a investigar — la reparación existe para que el usuario no quede atrapado mientras tanto.

Recuperación — replay determinista

FUNCIÓN recomputarEstado(eventos ordenados por created_at, secuencia):
  estado ← sin_diagnostico
  PARA cada e EN eventos:
    SI transicionValida(estado, e) ENTONCES estado ← aplicar(estado, e)
    SI NO marcar(e, "ignorado_en_replay") // jamás borrar — P3
  RETORNAR estado
// Propiedad exigida (IN-5): recomputarEstado es determinista y total —
// cualquier secuencia de eventos produce exactamente un estado, siempre el mismo.
