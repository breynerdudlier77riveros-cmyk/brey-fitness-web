Casos de reparación de estados imposibles

Motor BPS Handbook especifica una tabla de estados imposibles y su reparación — cada fila de esa tabla es un caso de test que construye deliberadamente el estado corrupto (vía inserción directa de datos de fixture, nunca vía el flujo normal) y verifica que el mecanismo de reparación/detección (evento anomalia) se dispara correctamente.
