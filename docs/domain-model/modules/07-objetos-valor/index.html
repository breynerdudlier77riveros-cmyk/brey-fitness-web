Módulo 07 · Entidades

Objetos de Valor

Trece value objects — sin identidad propia, definidos enteramente por su valor. Ninguno introduce una métrica fisiológica nueva; todos citan el handbook donde ya fueron validados.

VO-01

Peso

Representa
Masa corporal total
Unidades
Kilogramos (kg)
Comparabilidad
Totalmente ordenable, con magnitud — permite delta absoluto y relativo
Validación conceptual
20–300 kg (BCS Handbook, 03) — nota: el peso_kg del Perfil de Core Product usa un chequeo más laxo (>20) por ser un dato de contexto general, no de seguimiento clínico
VO-02

Altura

Representa
Estatura del Usuario/Cliente
Unidades
Centímetros (cm)
Comparabilidad
Ordenable, relativamente estable en el tiempo para un adulto
Validación conceptual
100–230 cm (BCS Handbook, 03)
VO-03

PorcentajeGrasa

Representa
Proporción del peso correspondiente a masa grasa
Unidades
Porcentaje (%)
Comparabilidad
Ordenable — nunca comparable entre dispositivos distintos sin advertencia (BCS Handbook, 03: 🏭 depende del fabricante)
Validación conceptual
3–60% (BCS Handbook, 03)
VO-04

MasaMuscular

Representa
Peso estimado de tejido muscular esquelético
Unidades
Kilogramos (kg)
Comparabilidad
Ordenable — cambia lento, una variación grande en poco tiempo es sospechosa (BCS Handbook, 03)
Validación conceptual
10–90 kg (BCS Handbook, 03)
VO-05

IMC

Representa
Relación Peso/Altura² — proxy poblacional de adiposidad
Unidades
kg/m²
Comparabilidad
Ordenable, pero su clasificación no está validada para población de alta masa muscular (BCS Handbook, 03, 06 — 🔬)
Validación conceptual
10–80 kg/m² (BCS Handbook, 03) — value object derivado, nunca capturado directamente
VO-06

ÁnguloFase

Representa
Ángulo derivado de resistencia/reactancia de la impedancia
Unidades
Grados (°)
Comparabilidad
Ordenable como tendencia únicamente — sin clasificación de salud aplicada (BCS Handbook, 03: 🏭)
Validación conceptual
2–12° orientativo (BCS Handbook, 03)
VO-07

RPE

Representa
Esfuerzo percibido reportado en una Serie
Unidades
Escala 0–10
Comparabilidad
Ordenable dentro de una banda de tolerancia ±1 respecto al objetivo (Progression Engine Handbook, PE-007)
Validación conceptual
Mutuamente excluyente con RIR dentro del mismo Slot (PE-ADR-05)
VO-08

RIR

Representa
Repeticiones en reserva estimadas al fallo
Unidades
Entero ≥0
Comparabilidad
Ordenable dentro de banda ±1 (Progression Engine Handbook, PE-008)
Validación conceptual
Mutuamente excluyente con RPE dentro del mismo Slot
VO-09

Dolor

Representa
Señal cruda interpretada exclusivamente por Recovery Engine
Unidades
Fuera de alcance de este handbook — Recovery Engine no tiene handbook de dominio propio (05, PR-05)
Comparabilidad
Fuera de alcance
Validación conceptual
Ningún otro contexto la recibe directamente (P8, LU-18)
VO-10

Fatiga

Representa
Señal cruda interpretada exclusivamente por Recovery Engine
Unidades
Fuera de alcance de este handbook
Comparabilidad
Fuera de alcance
Validación conceptual
Ídem VO-09 — ver LU-18 para la frontera exacta
VO-11

TiempoDescanso

Representa
Descanso prescrito entre Series
Unidades
Segundos
Comparabilidad
Ordenable — se ajusta por RIR reportado, nunca por debajo de un piso de seguridad (Progression Engine Handbook, PE-006)
Validación conceptual
Siempre >0
VO-12

Tempo

Representa
Ritmo de ejecución por fase de la repetición
Unidades
Notación por fase (excéntrica-pausa-concéntrica-pausa)
Comparabilidad
No ordenable de forma útil — es categórico, no una magnitud a comparar
Validación conceptual
Inmutable por autorregulación — solo cambia por prescripción de programa (Progression Engine Handbook, PE-005)
VO-13

Duración

Representa
Tiempo real u objetivo de una sesión
Unidades
Minutos
Comparabilidad
Ordenable — 3 sesiones consecutivas sobre-tiempo disparan reducción de volumen (Progression Engine Handbook, PE-009)
Validación conceptual
Siempre >0
