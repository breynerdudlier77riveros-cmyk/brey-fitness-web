Accesibilidad

BCS Design System Handbook (15) especifica los requisitos de accesibilidad del panel y la vista pública. Este documento no repite esa especificación — la convierte en casos: cada regla de contraste/foco/lectura de pantalla de ese módulo es un caso de test de e2e con herramienta de auditoría de accesibilidad, ejecutado tanto sobre el panel del Entrenador como sobre la vista pública del Cliente por separado (no basta con probar una y asumir la otra, porque son superficies de renderizado distintas, IN-A1 del BCS Handbook).

Estados — cada uno con su propio caso

BCS Design System Handbook (13) especifica los estados de carga/vacío/error del panel y la vista pública. Cada estado es un caso de e2e independiente: Cliente sin Mediciones (estado vacío explícito, nunca una sección en blanco sin explicación), enlace revocado o inexistente (pantalla de estado dedicada, nunca un error genérico de servidor, BCS Design System Handbook 13/BCS Handbook 10), y el estado de carga mientras el Reporte se computa.

Candidatos a regresión visual

Los gráficos de tendencia y las comparaciones (BCS Design System Handbook, 11, 12) son la superficie de mayor riesgo de regresión visual silenciosa — un cambio en la librería de gráficos o en el sistema de color puede alterar la interpretación de una tendencia sin que ningún test funcional lo detecte. Se especifican como candidatos a snapshot visual el día que exista la herramienta (12), sin comprometer cuál herramienta se usará (16).
