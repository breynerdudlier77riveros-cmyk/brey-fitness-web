Módulo 13 · Garantías

Evidencia Científica

Preguntas 26 y 27. El ecosistema tiene un sistema de niveles de evidencia riguroso y ampliamente aplicado — y ningún mecanismo para propagar un cambio de evidencia a las entradas existentes.

El sistema de cuatro niveles

Ciencia marcada, nunca inventada

"Toda regla con base fisiológica lleva un badge de nivel de evidencia: consenso sólido · evidencia moderada · hipótesis · decisión de producto. El cuarto badge es el más importante: marca los números y reglas que NO provienen de evidencia científica sino de una decisión de diseño calibrable. Confundir decisiones de ingeniería con decisiones científicas es un error de integridad, no de estilo. Una regla sin badge es puramente estructural y no hace ningún reclamo fisiológico."

Pregunta 26 · ¿Qué sucede si cambia la evidencia científica?

Para las reglas, la respuesta es completa

El ecosistema anticipa el cambio de evidencia: marca qué reglas dependen de ella, distingue las que son decisión de diseño, declara los umbrales calibrables y define el mecanismo de actualización (ADR, sin edición silenciosa). Es un diseño maduro, y funciona hasta el borde del catálogo.

Pregunta 27 · ¿Cómo afecta a entradas existentes?

CL-D11 — el catálogo no participa del sistema de evidencia

El sistema de badges se aplica a las reglas de los handbooks y a ningún dato del catálogo. Ninguna fuente exige que una asignación de patrón, rol o zona de riesgo declare en qué se basa.

La asimetría es notable: una regla que dice "el descanso del principal es 120–180 s" debe llevar badge; una etiqueta que afirma "este ejercicio carga la rodilla en alto" no lleva ninguno — pese a ser la afirmación con más consecuencias de seguridad del ecosistema, y pese a que la fuente exige para ella "criterio biomecánico".

La cadena rota

Cinco eslabones, dos disponibles

Propagar un cambio de evidencia a las entradas existentes exigiría, en orden: (1) saber qué entradas dependían de esa evidencia → falta declaración de base (CL-D11); (2) marcarlas para reevaluación → faltan estados (CL-D05); (3) disparar la revisión → falta proceso de revisión; (4) registrar quién la reevaluó → falta autoría (CL-D09); (5) versionar el resultado → esto sí existe, a nivel de catálogo.

De los cinco eslabones, solo el último funciona. Y funciona sobre el objeto equivocado.

Cambio de clasificación de un ejercicio—❌ No contemplado
El badge advierte; no gobierna

Marcar una regla como hipótesis declara honestamente su fragilidad, pero no define qué ocurre si la hipótesis se refuta: no hay revisión programada, ni responsable, ni consecuencia declarada. El sistema de evidencia es excelente documentando el estado del conocimiento y no define ningún proceso para cuando ese estado cambia.
