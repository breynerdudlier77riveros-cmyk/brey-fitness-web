Módulo 03 · Planificación

Roadmap

Cinco fases. Cada una tiene una condición de entrada (qué debe estar cerrado antes de empezarla) y una condición de salida (qué desbloquea).

Las cinco fases — la Fase 1 se divide en dos pistas paralelas

FASE 0

Fundación

Entrada: ninguna — es el punto de partida.

Contenido: IMP-ADR-01 (forma canónica del Veredicto de Recovery, 14), migración de endurecimiento RLS (05, M1), verificación de que Core Product sigue en estado verificado.

Salida: desbloquea las dos pistas de la Fase 1 en paralelo.

FASE 1 · PISTA A

Body Composition System

Entrada: Fase 0 cerrada; IMP-ADR-06 (mapeo de columnas del BCS, 14) aceptado.

Contenido: migración de tablas BCS (05, M3) → repositorios y casos de uso del BCS (06) → componentes del BCS Design System (07).

Salida: BCS listo para uso real por un entrenador — no depende de la Pista B para funcionar.

FASE 1 · PISTA B

Motores

Entrada: Fase 0 cerrada.

Contenido: contrato mínimo de Recovery Engine (IMP-ADR-01) → migración de progression_events (05, M2) → Motor BPS (orquestador) y Progression Engine (lógica pura de las 39 reglas) construidos en paralelo entre sí (02) → Diagnóstico BPS conectado a persistencia real (hoy efímero).

Salida: ambos motores listos para integrarse entre sí.

FASE 2

Integración

Entrada: Fase 1 Pista B cerrada (Motor BPS y Progression Engine ya existen individualmente).

Contenido: pipeline completo de invocación Motor BPS → Recovery → Progression Engine end-to-end (09), primer ciclo semanal real ejecutado sobre datos de un usuario de prueba.

Salida: el ciclo de progresión automática funciona de extremo a extremo.

FASE 3

Endurecimiento

Entrada: Fase 2 cerrada.

Contenido: cobertura de testing de los casos críticos (10), instrumentación de observabilidad completa (11), aplicación de los índices de base de datos ya especificados y nunca aplicados (Engineering Handbook, 05).

Salida: el sistema está listo para producción con usuarios reales en volumen, no solo en modo demo.

FASE 4

Expansión futura

Entrada: Fase 3 cerrada.

Contenido: Workout Generator, Workout Player, Nutrición, Programas, Coach IA, Hábitos, Lesiones — ninguno tiene handbook de dominio propio todavía. Fuera del alcance operativo de este roadmap hasta que exista su especificación (00, Engineering Handbook).

Salida: n/a — cada módulo nuevo repite el ciclo completo desde su propio handbook de dominio.
