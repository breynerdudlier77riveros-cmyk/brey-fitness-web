Validación de rango — VALOR_FUERA_DE_RANGO_FISICO

Ninguna variable de masa puede exceder peso_kg (bloqueante, 07). masa_grasa_kg + masa_libre_grasa_kg ≈ peso_kg (±0.5kg) y agua_intracelular_l + agua_extracelular_l ≈ agua_total_l son advertencias, no bloqueos (BCS Handbook, 03).

Por qué progression_events.contexto no tiene una tabla de campos internos aquí

A diferencia de los dos jsonb de arriba, contexto no tiene forma fija por tipo de evento — es un gap ya identificado (AR-013/AR-026), no una omisión de este documento. Inventar campos internos para contexto violaría la restricción de no inventar información; se documenta como pregunta abierta (16).
