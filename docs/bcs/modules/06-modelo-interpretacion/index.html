Módulo 06 · Reporte

Modelo de Interpretación

Cómo el sistema clasifica valores en texto legible ("normal", "alto", "bajo") sin cruzar jamás la línea hacia el diagnóstico médico. El módulo con la responsabilidad más delicada de todo el handbook.

Principio rector

Regla no negociable

BCS interpreta tendencias numéricas, nunca estado de salud. Toda clasificación que el sistema muestre es una posición relativa dentro de un rango de referencia citado — nunca una afirmación sobre si el cliente está sano, enfermo, en riesgo o requiere atención médica. El lenguaje generado evita sistemáticamente términos clínicos con peso diagnóstico ("patológico", "riesgo de enfermedad") y usa en su lugar términos descriptivos ("por debajo del rango de referencia habitual").

El aviso poblacional — declarado una vez, aplicado en cada variable

La mayoría de rangos de referencia disponibles en la literatura (IMC, WHR, SMI) fueron desarrollados y validados en población general, no en población de entrenamiento de fuerza — el perfil típico de cliente de un entrenador que usa BCS. Una persona con alta masa muscular puede clasificar como "sobrepeso" por IMC sin tener exceso de grasa real. Este aviso se declara aquí formalmente y se referencia desde cada ficha de variable en 03 en vez de repetirse íntegro en cada una.

Ejemplo de texto generado

EntradaTexto generado
IMC = 27.8"IMC de 27.8 kg/m² — por encima del rango de referencia general para adultos (18.5–24.9). Este rango no está validado para personas con alta masa muscular; considerar junto al % de grasa corporal registrado."
Grasa visceral = 8 (escala InBody 1–20)"Índice de grasa visceral: 8, dentro del rango de referencia del fabricante del dispositivo usado (1–20 en esta escala)."
Masa muscular sube de 32.1 a 33.4 kg en 2 meses"Masa muscular: aumentó 1.3 kg desde la medición anterior."

Contraejemplos

  • El sistema NUNCA genera el texto "tienes riesgo de enfermedad cardiovascular" ni ningún enunciado de riesgo de salud atribuible a un valor.
  • El sistema NUNCA clasifica SMI ni ángulo de fase con una etiqueta de "normal/anormal" en v1 — no hay consenso suficiente (03).
  • El sistema NUNCA omite el aviso de procedencia cuando muestra una clasificación — el badge siempre acompaña al texto, nunca aparece el texto solo.

Casos límite

CasoComportamiento
Cliente menor de edadLos rangos de referencia de adultos no aplican — v1 no tiene rangos pediátricos; el sistema muestra el valor sin clasificación y con nota explícita (17, pregunta abierta)
