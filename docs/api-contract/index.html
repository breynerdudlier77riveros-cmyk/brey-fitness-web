BREY API Contract Handbook

Qué endpoints existen, quién puede llamarlos, qué reciben, qué devuelven y qué eventos disparan — para Motor BPS, Progression Engine, Recovery Engine, Workout, BCS y el resto del ecosistema. Sin código, sin SQL, sin funcionalidad nueva: solo el contrato ya implícito en los nueve handbooks existentes, formalizado.
