BREY Exercise Tagging Handbook v1.0

Cómo se asignan oficialmente los atributos de un ejercicio

BREY Exercise Tagging Handbook

El Exercise Taxonomy Handbook respondió qué atributos existen. Este responde cómo se asignan: el proceso oficial, la jerarquía de reglas ante conflicto, las validaciones que hacen inválido un etiquetado y el checklist de aceptación. Y declara con precisión cuantitativa qué parte de esa decisión el ecosistema define como criterio humano por diseño — en lugar de inventar la biomecánica que falta.
