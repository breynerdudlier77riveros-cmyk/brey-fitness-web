Módulo 13 · Sistema

Integración

Cómo este motor se conecta con el resto de BREY — quién lo invoca, a quién consulta indirectamente, quién consume su salida, y qué NO conoce directamente.

Objetivo

Que el contrato de integración de este motor con cada sistema vecino esté completamente especificado, sin zonas grises sobre quién inicia la comunicación.

Puntos de integración

SistemaRelaciónDirección
Motor BPSOrquestador — invoca este motor con las 5 entradas ya resueltas (04), aplica sus decisiones como transiciones/persistenciaMotor BPS → este motor → Motor BPS
Recovery EnginePrecede a este motor en la cadena de invocación — este motor nunca lo consulta directamente, solo recibe su Veredicto ya resueltoRecovery → Motor BPS → este motor (indirecta)
Workout GeneratorConsumidor directo de la Prescripción vigente resultanteEste motor → Workout Generator (vía Motor BPS)
Workout PlayerNinguna relación directa — el Player ejecuta lo que el Generator ya construyóN/A
Knowledge BaseFuente de cadenas de progresión y capacidades (entrada 4, módulo 04) — este motor lee posición en cadena, nunca contenido de eslabonesKnowledge Base → este motor
DiagnósticoNinguna relación directa — el Diagnóstico alimenta activación (Motor BPS), no progresiónN/A
Repositorio / Base de datosNinguna — este motor no hace I/O propio (IN-P1); toda persistencia la realiza el Motor BPS con los DTOs que este motor produceN/A directa
