Engineering Handbook

Cómo se construye técnicamente cualquier módulo de BREY — frontend, backend, base de datos, contratos, eventos, seguridad, performance, testing, observabilidad, despliegue y estándares. Verificado contra el código real, no aspiracional. Si el código futuro lo contradice, el handbook tiene prioridad.
