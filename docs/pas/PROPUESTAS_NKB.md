# Propuestas de admisión a la NKB

> Sprint PAS-11.2 · Fase 4 · **Ninguna ficha creada. Ninguna fuente admitida.**
>
> La NKB sigue siendo la única fuente de verdad normativa, y su procedimiento de
> admisión no lo ejecuta este documento: lo prepara. Cada propuesta declara qué
> afirmación individual permitiría sostener y qué le falta para merecer una
> ficha.

---

## Criterio aplicado

Una fuente solo se propone para admisión si supera las doce condiciones del §3
del encargo. La que falla una queda registrada en la capa de evidencia del PAS
—que es un registro de trabajo, no una base normativa— y no llega aquí.

| Destino | Qué significa |
|---|---|
| **ADMITIR** | Puede sostener una operación normativa. Merece ficha |
| **EVIDENCIA** | Útil para fiabilidad, benchmark o contexto. No posiciona |
| **EVIDENCIA NEGATIVA** | Verificada, y demuestra que NO puede usarse para lo que se pretendía |
| **RECHAZAR** | No cumple mínimos |

## PROPUESTA 1 · Hoffmann et al. 2019 — CHMS

**Destino: ADMITIR, con población canadiense declarada.**

| | |
|---|---|
| Referencia | Hoffmann MD, Colley RC, Doyon CY, Wong SL, Tomkinson GR, Lang JJ (2019). *Normative-referenced percentile values for physical fitness among Canadians.* Health Reports 30(10), Statistics Canada, Cat. 82-003-X |
| Localizador | doi:10.25318/82-003-x201901000002-eng · PMID 31617933 |
| N | 5 188 (50,1 % mujeres) |
| Edad | 6 a 69 años |
| País | Canadá · muestra nacionalmente representativa (CHMS ciclo 5, 2016-2017) |
| Variables | Altura de salto (cm) · sit-and-reach (cm) · más otras tres no transcritas |
| Estadístico | Percentiles P5, P10, P20, P30, P40, P50, P60, P70, P80, P90, P95 |
| Protocolo salto | Plataforma Leonardo Mechanograph, CMJ bilateral, **brazos libres**, mejor de 3 |
| Protocolo flexión | Flexómetro FitSystems, **tocar los dedos = 26 cm**, mejor de 2, con estiramiento previo |
| Nivel | A |

**Qué afirmación individual permite.** «Este resultado se sitúa entre el
percentil X y el Y de los publicados para varones canadienses de 20 a 24 años.»

**Qué NO permite.** Situar a nadie fuera de Canadá (ver G-06). Los propios
autores advierten además que una norma no equivale a un punto de corte de
salud: rendir por encima de un percentil no implica un nivel saludable.

**Qué falta para la ficha.** Transcribir las bandas restantes (6-7 a 65-69) y
las otras tres variables. Hoy solo están 20-24 y 25-29 de ambos sexos.

## PROPUESTA 2 · Ramírez-Vélez et al. 2017 — FUPRECOL

**Destino: ADMITIR, con población escolar declarada.**

| | |
|---|---|
| Referencia | Ramírez-Vélez R, Palacios-López A, Prieto-Benavides DH, Correa-Bautista JE, Izquierdo M, Alonso-Martínez A, Lobelo F (2017). *Normative reference values for the 20 m shuttle-run test… the FUPRECOL study.* Am J Hum Biol 29(1):e22902 |
| Localizador | doi:10.1002/ajhb.22902 · PMID 27500986 |
| N | 7 244 escolares (55,7 % niñas) |
| Edad | 9 a 17,9 años |
| País | Colombia · Bogotá, 2 625 m de altitud, colegios públicos |
| Estadístico | Percentiles P3, P10, P25, P50, P75, P90, P97 |
| Protocolo | Course-navette 20 m; VO₂pico estimado con Léger (1988) |
| Nivel | A |

**Es la única fuente colombiana localizada en todo el proyecto además de la
dinamometría.** Merece ficha por eso, aunque su población no sea la del atleta
que hoy usa el sistema.

**Qué NO permite.** Aplicarse a adultos. El sistema debe poder decir «existe una
norma para esta prueba, pero no para tu población», que es distinto de «no
existe evidencia».

**Qué falta para la ficha.** Transcribir la tabla de percentiles: hoy la
referencia está registrada como `valores_sin_transcribir`.

## PROPUESTA 3 · van den Hoek et al. 2024 — Powerlifting

**Destino: EVIDENCIA (benchmark). NO admitir como norma.**

| | |
|---|---|
| Referencia | van den Hoek DJ y cols. (2024). *Normative data for the squat, bench press and deadlift exercises in powerlifting.* J Sci Med Sport 27(10):734-742 |
| Localizador | doi:10.1016/j.jsams.2024.07.005 |
| N | 809 986 inscripciones en competición |
| Población | Competidores federados, sin equipamiento, con control antidopaje |
| Estadístico | Percentiles 10.º a 90.º de carga ÷ masa corporal |

**Por qué no se admite como norma.** La muestra son competidores federados, no
una población. Un percentil dentro de ella dice dónde cae alguien *entre
powerlifters de competición*, y leerlo como posición poblacional multiplicaría
el rigor de la afirmación por cero. El título del artículo dice «normative
data», y eso no lo convierte en una norma poblacional.

**Además, hoy es inaplicable**: sus valores son relativos a la masa corporal, y
el PAS no la registra (G-01).

## PROPUESTA 4 · Bagchi et al. 2024 — CMJ

**Destino: EVIDENCIA (fiabilidad). NO admitir como norma.**

| | |
|---|---|
| Referencia | Bagchi A, Raizada S, Thapa RK, Stefanica V, Ceylan HI (2024). *Reliability and Accuracy of Portable Devices for Measuring Countermovement Jump Height in Physically Active Adults.* Life (Basel) 14(11):1394 |
| Localizador | doi:10.3390/life14111394 |
| N | 22 deportistas universitarios |
| Estadístico | ICC 0,981-0,987 · CV 6,1-7,3 % |

**Por qué no se admite como norma.** No contiene ningún valor normativo. Es un
estudio de fiabilidad entre dispositivos, y 22 personas no describen ninguna
población. **No publica SEM ni MDC**, así que tampoco autoriza a decir si un
cambio observado es real.

## PROPUESTA 5 · Triplett et al. 2021 — FMS

**Destino: EVIDENCIA NEGATIVA. NO admitir.**

| | |
|---|---|
| Referencia | Triplett CR y cols. (2021). *Functional Movement Screen Detected Asymmetry & Normative Values Among College-Aged Students.* IJSPT 16(2):450-458 |
| Localizador | doi:10.26603/001c.19443 · PMID 33842040 |
| N | 100 universitarios (57 mujeres, 43 varones), 18 a 26 años, EE. UU. |
| Estadístico | Media 14,40 · moda 16 · recorrido observado 7-19 |

**Por qué es evidencia negativa y no una carencia.** La población es
perfectamente compatible con el atleta del sistema —18 a 26 años— y aun así la
fuente **no publica ninguna distribución**. Un recorrido muestral no es un rango
de referencia: convertir el mínimo y el máximo de 100 personas en los extremos
de una escala fabricaría una norma que nadie publicó.

Está verificada, y de ella no cuelga ninguna referencia. Un test lo garantiza.

## PROPUESTA 6 · Alkhathami et al. 2021 — FMS

**Destino: EVIDENCIA NEGATIVA. NO admitir.**

| | |
|---|---|
| Referencia | Alkhathami K, Alshehre Y, Wang-Price S, Brizzolara K (2021). *Reliability and Validity of the FMS with a Modified Scoring System for Young Adults with Low Back Pain.* IJSPT 16(3):620-627 |
| Localizador | doi:10.26603/001c.23427 · PMID 35655963 |
| Estadístico | ICC 0,99 · SEM 0,38 · **MDC95 1,05 puntos** |

**Por qué es evidencia negativa.** El MDC es excelente y **corresponde a un
sistema de puntuación modificado**, no al FMS estándar de 0 a 21. Trasladarlo
sería aplicar el error de una prueba a otra distinta. Es la trampa más fácil de
todo el catálogo, porque la cifra es tentadora y la fuente es buena.

## PROPUESTA 7 · Rouis et al. 2016 — Ascendencia y salto

**Destino: EVIDENCIA (justifica una regla de compatibilidad). NO admitir.**

| | |
|---|---|
| Referencia | Rouis M, Coudrat L, Jaafar H, Attiogbé E, Vandewalle H, Driss T (2016). *Effects of ethnicity on the relationship between vertical jump and maximal power on a cycle ergometer.* J Hum Kinet 51:209-216 |
| Localizador | doi:10.1515/hukin-2015-0184 · PMID 28149384 |
| N | 31 varones: 15 afrocaribeños, 16 caucásicos |
| Resultado | CMJ 62,9 ± 6,7 cm frente a 52,9 ± 4,4 cm · p < 0,001 |

**Uso legítimo, y solo ese.** Sostiene la decisión de G-06 para el salto. No
sitúa a nadie, no clasifica por ascendencia y no autoriza a corregir un
resultado por ella. Demuestra únicamente que la composición poblacional de una
muestra normativa importa.
