Módulo 06 · Componentes y pantallas

Componentes

BREY ya tiene 18 componentes de marca reutilizables. El BCS no los reemplaza — compone 7 componentes nuevos específicos del dominio a partir de ellos, y documenta cómo usa los heredados.

Componentes nuevos de este dominio

BCS-C01nuevo

Metric Card

Composición
Compone Card heredado (rounded-2xl, border white/[0.07]) + valor numérico en tabular figures (04) + badge de tendencia (Indicador, BCS-C07) + badge de procedencia (BCS Handbook, 00)
Contenido
Nombre de variable, valor + unidad, delta vs. medición anterior, badge de procedencia
Interactividad
No clicable por defecto — es de solo lectura; usa cardStyles.base, nunca .interactive
Cuándo se usa
Grid de 3 columnas en el Dashboard (07) y en el Reporte (09)
Contraejemplo
Nunca muestra un valor numérico sin unidad ni badge de procedencia (04, 01 Claridad)
BCS-C02nuevo

Section Card

Composición
Compone Card + CardHeader/CardTitle heredados — contenedor de una sección completa del Reporte (Ficha actual, Histórico, Comparación)
Contenido
Título de sección (h2, 04), contenido variable (tabla, gráfico, o grid de Metric Cards)
Interactividad
Puede colapsarse en mobile (07) — usa Accordion heredado internamente cuando colapsa
Cuándo se usa
Estructura raíz de cada bloque del Reporte (BCS Handbook, 04)
Contraejemplo
Nunca anida una Section Card dentro de otra Section Card
BCS-C03nuevo

History Card

Composición
Fila compacta: fecha + 3–4 variables clave + ícono de expansión — al expandir muestra la Ficha completa de esa Medición
Contenido
Fecha (destacada), variables clave configurables, indicador de "corregida" si aplica (BCS Handbook, 05)
Interactividad
Clicable — expande/colapsa; usa cardStyles.interactive
Cuándo se usa
Lista del Histórico completo (BCS Handbook, 05)
Contraejemplo
Nunca muestra una Medición anulada — solo vigentes (BCS Handbook, IN-D1)
BCS-C04nuevo

Warning Card

Composición
Variante de Card con borde izquierdo amarillo (05) + ícono de advertencia + texto — para valores sospechosos (BCS Handbook, 03)
Contenido
Descripción del valor sospechoso, variable afectada, nunca una acción de "corregir" inline (eso requiere el flujo completo de CorregirMedición)
Interactividad
No clicable — informativa
Cuándo se usa
Junto a una Metric Card o History Card cuyo valor esté marcado sospechoso
Contraejemplo
Nunca usa el rojo de error (05) — el amarillo de advertencia y el rojo de error tienen significados distintos y no son intercambiables (Ley 2)
BCS-C05nuevo

Info Card

Composición
Variante de Card con borde izquierdo azul + ícono de información — para el aviso poblacional y notas de procedencia (BCS Handbook, 06)
Contenido
Texto explicativo, nunca una cifra propia
Interactividad
No clicable
Cuándo se usa
Junto a clasificaciones con aviso poblacional (IMC, WHR — BCS Handbook, 06)
Contraejemplo
Nunca se usa para errores ni advertencias — esos tienen sus propias tarjetas (BCS-C04, ver también Estados, 13)
BCS-C06nuevo

Indicador de tendencia

Composición
Ícono (↑/↓/→) + texto corto ("+1.3 kg") — nunca solo color, nunca solo ícono (01, Accesibilidad)
Colores
Emerald si la dirección coincide con "mejora" (BCS Handbook, 05); Red si es "retroceso"; Neutral (blanco apagado) si Peso/IMC sin dirección asignada
Interactividad
No clicable
Cuándo se usa
Metric Card, History Card, Comparación (12)
Contraejemplo
Nunca aparece un ↑ o ↓ sin el valor numérico del delta junto a él
BCS-C07nuevo

Skeleton

Composición
Bloques rectangulares rounded-2xl con animación de pulso sutil, del mismo tamaño y posición exactos que el contenido real que reemplazan (13, estado de Carga)
Color
rgba(255,255,255,0.04) con un shimmer que va a 0.07 — nunca colores semánticos (05)
Duración de animación
1.5s, ease-in-out, infinito — respeta prefers-reduced-motion (16): se vuelve estático, sin pulso
Cuándo se usa
Carga inicial del Dashboard, carga de un Reporte con historial grande (12, 13)
Contraejemplo
Nunca un spinner genérico reemplazando toda la pantalla — el Skeleton preserva el layout para evitar salto de contenido (CLS)

Matriz de cobertura — ninguna métrica sin componente

Verificación cruzada con el catálogo de 25 variables del BCS Handbook (03): toda variable numérica se renderiza en Metric Card (BCS-C01) dentro de una Section Card (BCS-C02); toda variable con clasificación (BCS Handbook, 06) puede llevar Warning Card o Info Card adjunta según corresponda.
