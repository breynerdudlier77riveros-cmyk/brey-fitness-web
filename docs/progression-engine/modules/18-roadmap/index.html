Roadmap

Qué debe pasar antes de implementar, qué queda deliberadamente fuera de v1, y qué depende de trabajo externo a este documento.

Prerequisitos de implementación (bloqueantes)

PrerequisitoPor qué bloquea
Extender el CHECK de progression_events (Architecture Handbook, 10) con los 9 tipos de evento de este documentoSin esto, el Motor BPS no puede persistir legalmente las salidas de este motor (15, 17)
Confirmar el contrato mínimo del Veredicto de Recovery con el futuro Recovery Engine HandbookEs una entrada obligatoria no nulable (04) — cualquier cambio de forma rompe este documento

Alcance de v1.0 (este handbook)

Las 39 reglas del catálogo (07), el pipeline de 9 pasos (06), micro/macro/autorregulación/estancamiento/deload completos según lo especificado en 08–12. Nada de esto es candidato a recorte — es el mínimo funcional coherente.

Candidatos para v1.1 (post-calibración)

CandidatoCondición para promoverlo
Progresión combinada (subir carga y repeticiones el mismo ciclo)Evidencia de que la restricción actual (PE-012) genera fricción real medible en datos de producción
Sistemas de esfuerzo mixtos (RPE y RIR en el mismo Slot)Un caso de programa real de Training Framework que lo requiera — no especulativo (19)
Deload preventivo (PE-035) pasa de sugerencia a vinculanteDatos de al menos un ciclo de producción mostrando tasa de confirmación y resultado positivo medible (14)
Recalibración de umbrales de tolerancia macro (PE-014, PE-017)Volumen suficiente de ciclos completados para un análisis estadístico serio, no ajuste anecdótico

Explícitamente fuera de cualquier versión de este motor

  • Decisión de Track/Sistema (PE-018) — pertenece permanentemente al Motor BPS.
  • Interpretación directa de dolor/fatiga/sueño (PE-023–025) — pertenece permanentemente a Recovery.
  • Selección de ejercicios por nombre — pertenece permanentemente a la Knowledge Base.

Dependencias de trabajo externo a este handbook

El Recovery Engine Handbook (aún no escrito) es la única dependencia externa activa — mientras no exista, este documento opera con el contrato mínimo ya usado por el Motor BPS Handbook, que es estable pero no exhaustivo. Ningún otro handbook pendiente bloquea este documento.
