Recovery DTO — forma canónica

Forma adoptada por este documento — API-ADR-02

Este documento adopta la forma reconciliada del Implementation Handbook (IMP-ADR-01): {procede: boolean, subtipo?: "programada" | "reactiva", razon: string}. No es una forma nueva inventada aquí — es la que el nivel de mayor autoridad ya decidió para efectos de implementación (ver jerarquía, 00).

CampoTipoObligatorioNota
procedebooleanSíReemplaza el si de Motor BPS Handbook — booleano sin chequeo de nulidad adicional
subtipo"programada" | "reactiva"Solo si procede: trueRenombrado desde tipo (Motor BPS Handbook) para no colisionar con el tipo ya usado por Progression Engine Handbook para un eje semántico distinto
razonstringSí, siempreObligatoria incluso cuando procede: false — más estricta que la forma opcional de Motor BPS Handbook
Formas históricas no editadas — no son un error de este documento

Motor BPS Handbook (03) y el propio módulo de Recovery Engine del Architecture Handbook (06) siguen mostrando {si, tipo?: programada|reactiva, razon?}; Progression Engine Handbook (04) sigue mostrando {procede: boolean, tipo: "normal"|"descarga", razon: string}. Ninguno de los tres se edita desde aquí (AR-001) — este documento cita la forma canónica de implementación, no reescribe los handbooks de origen.
