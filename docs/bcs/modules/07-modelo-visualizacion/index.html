Reglas de diseño conceptual

  • Ninguna barra de progreso se muestra sin su badge de procedencia (03/06) visible junto a ella — la barra nunca se presenta como si fuera un hecho médico establecido.
  • Los gráficos de tendencia nunca interpolan entre puntos con huecos grandes de tiempo como si fueran continuos — un hueco de meses se marca visualmente distinto a mediciones consecutivas semanales.
  • El eje de una variable derivada (03) nunca se combina con el de una variable cruda en el mismo gráfico, salvo que ambas compartan unidad — evita comparaciones visuales engañosas.
  • Toda variable marcada 🔬 o 🏭 (00, 03) lleva su badge visible en cualquier visualización donde aparezca, sin excepción.

Paridad con el módulo 04

La vista pública y la vista privada renderizan las mismas visualizaciones (04). La única diferencia visual permitida entre ambas superficies es la ausencia de controles interactivos de edición — nunca una reducción del contenido informativo mostrado.
