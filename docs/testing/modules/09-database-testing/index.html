Migraciones — prueba de idempotencia del propio archivo

El patrón real de migración (ADD COLUMN IF NOT EXISTS, bloques DO $$ para constraints) se prueba aplicando el mismo archivo dos veces consecutivas contra una base de test limpia — la segunda aplicación no debe producir error ni cambiar el estado resultante (Database Handbook, 11). Este es un test de integration sobre el propio artefacto de migración, no sobre datos de aplicación.
