CHECK vs. enum nativo — ENG-ADR-02

Los 19 CHECK de arriba son text + CHECK, nunca CREATE TYPE ... AS ENUM de Postgres — decisión ya tomada por el Engineering Handbook (ENG-ADR-02): ALTER TYPE ... ADD VALUE tiene restricciones históricas de transacción que CHECK no tiene, y añadir un valor nuevo a cualquier enumerado del sistema es una migración simple y simétrica con TypeScript.
