Cuándo introducir un Application Service

Ninguno de los pasos anteriores lo requiere todavía — cada uno invoca como máximo un repositorio o un motor puro. El primer candidato real (Engineering Handbook, ENG-ADR-01) es el paso "Cálculo del Reporte" del BCS (Pista A, #5), que combina Cliente + Mediciones + interpretación — si su complejidad crece más allá de una función de orquestación simple, es el punto de introducir la capa formal, no antes.

Servicios externos

Ningún paso de este módulo requiere un servicio externo nuevo — Brevo (ya integrado) no participa en ningún flujo de BCS ni de los motores. Si un futuro Coach IA requiere un LLM externo, sigue el mismo patrón que app/api/lead (Engineering Handbook, 06): Route Handler con manejo de error tipado, nunca lógica de negocio dentro del cliente HTTP.
